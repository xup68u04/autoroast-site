autoroast

家用咖啡烘豆機的控制與紀錄工具，包含 Android App 與 Windows 桌面版「烘焙站」。這是開發者自己使用的工具，沒有上架，也不提供給其他人使用。

這個 App 做什麼

  • 透過藍牙連線烘豆機，顯示即時溫度曲線，調整火力與風量，記錄一爆、下豆等事件。
  • 每鍋烘完後，把烘焙紀錄存在本機，並另存成 JSON 檔。
  • 使用者登入後，把這份 JSON 上傳到使用者自己 Google 雲端硬碟裡的指定資料夾，供日後比對與杯測回顧。

它如何使用 Google 帳戶

App 以使用者本人的 Google 帳戶登入，只用來把烘焙紀錄寫進使用者自己的雲端硬碟資料夾。 資料只存在使用者自己的裝置與使用者自己的雲端硬碟裡，開發者沒有另外的伺服器。
